مصطفى الحمداني — حزمة PS4 حتى 14.00
تاريخ التجهيز: 11 نوفمبر 2026

هذه حزمة ملفات موقع جاهزة للرفع، وليست نتيجة تجربة على جهاز PS4.
لم تُرفع إلى حساب GitHub ولم تُنشر في هذه المهمة.

الإضافات:
- نفس الصورة والاسم والعنوان والأرقام الموجودة بالنموذج المقبول.
- واجهة تغطي مساحة الشاشة؛ تُحفظ أبعاد الصورة لتجنب قص الكتابة.
- الضغط بأي مكان أو X/Enter يبدأ محاولة التشغيل بعد اكتمال الكاش.
- كشف إصدار PS4 تلقائياً، مع قائمة صريحة تمنع الإصدارات المجهولة و14.01 فما فوق.
- الملفات محلية، وتشغيل المحمل داخل الصفحة نفسها دون موقع خارجي.
- ملفات GoldHEN 2.4b18.13 ومسار 14.00: slopkit/jb2.js + afterglow.js + patches/1400.bin.
- كاش Application Cache الأصلي المستخدم في مصادر PS4؛ لا يعتمد على Service Worker.
- أول زيارة تبدأ حفظ الملفات تلقائياً. النسبة تمثل عدد الملفات، وليست نسبة نجاح التعديل.
- رسائل أخطاء فعلية وعدم تكرار التشغيل في الجلسة نفسها.
- تختفي رسالة النجاح بعد إبلاغ المحمل بالنجاح. تأكد من قائمة GoldHEN على جهازك.

الرفع على GitHub Pages:
1. فك ضغط الحزمة.
2. ارفع محتويات مجلد MUSTAFA-PS4-14 كاملة، بحيث يكون index.html في جذر الموقع أو مجلده المطلوب.
3. أبقِ المجلدات والأسماء كما هي. ارفع offline.manifest وملف .nojekyll أيضاً.
4. فعّل GitHub Pages من Settings > Pages للمستودع المطلوب.
5. افتح عنوان الموقع النهائي من متصفح PS4 وهو متصل بالإنترنت أول مرة.
6. انتظر «اكتمل حفظ ملفات الأوفلاين». اضغط X للتشغيل إذا لم تكن ضغطته أثناء الحفظ.
7. تحقق من ظهور GoldHEN، ثم افصل الإنترنت وأغلق المتصفح وافتح نفس العنوان لاختبار الأوفلاين.
8. اختبر مرة أخرى بعد إطفاء الجهاز وتشغيله؛ التعديل يحتاج إعادة تشغيل بعد إقلاع الجهاز.
إذا ظهر أن الكاش غير متاح، لم يتم حفظ الأوفلاين. لا تعتمد على ظهور الصورة وحده.
إذا ظهر تحديث الملفات، أغلق المتصفح وافتحه مجدداً قبل التشغيل.
فتح index.html مباشرة على الكمبيوتر لا يختبر التعديل أو كاش PS4.

الفحوص المنفذة:
- فحص صياغة JavaScript المحلي.
- 16 حالة فحص لمحمل الواجهة: توجيه الإصدارات، انتظار الكاش، نجاحه وفشله وتحديثه، منع التكرار، منع الكمبيوتر والإصدارات غير المدعومة.
- تحقق وجود جميع ملفات قائمة الكاش بما فيها مسارات query string المطلوبة.
- مطابقة ملفات تشغيل 900 وcss وslopkit مع المصدر دون تغيير بالبايت.
- ملفات التشغيل لم تُنفذ على الكمبيوتر أثناء الفحص.

غير مختبر:
- عرض الواجهة في متصفح PS4 الحقيقي.
- نجاح الاستغلال واستقرار GoldHEN على الجهاز.
- حفظ الكاش وإعادة فتح الموقع دون إنترنت على الجهاز.
- تفاعل زر X الحقيقي في متصفح PS4؛ الكود يتعامل مع Enter وStandard Gamepad button 0.
